# ResumeSmint — Full-Stack Career Platform 🚀

ResumeSmint is a full-stack career platform designed to help users create professional resumes, discover relevant job opportunities, track job applications, and prepare for interviews.

## ✨ Features

- 🔐 User Signup & Login Authentication
- 📄 Resume Builder with Multiple Templates
- 👀 Resume Live Preview
- 🤖 AI-Powered Job Recommendations
- 🔎 Dedicated Job Search
- 📌 Job Application Tracking
- 🎯 Interview Preparation
- 📱 Responsive User Interface
